# SUPERVISED LEARNING WORKFLOW GUIDE
# ===================================
# This guide explains how to test and run the SL workflow from square one
# Database: trade_data.db (SQLite database in the db/ folder)

## PREREQUISITES
================

1. **Python Environment**
   - Ensure you have Python 3.8+ installed
   - Activate your virtual environment: `.venv\Scripts\Activate.ps1` (PowerShell)
   - Install required packages: `pip install -r requirements.txt`

2. **Database Setup**
   - The SL system connects to: `db/trade_data.db`
   - This is the same SQLite database used by your RL system
   - Make sure the database exists and has data

3. **Required Data**
   - Historical data in `historical_data_1h` table
   - Processed candles with technical indicators in `processed_candles_with_ta.csv`
   - News sentiment data (optional)

### STEP 4: TEST DATA PREPARATION
--------------------------------
```powershell
# Test data preparation (this will create training data)
python supervised\sl_workflow.py --action prepare_data --symbols /ES:XCME /NQ:XCME
```

**What this does:**
- Loads data from `db/processed_candles_with_ta.csv`
- Creates classification labels based on future returns
- Adds engineered features (price ratios, volatility, momentum)
- Saves processed data to `outputs/sl_training_data_YYYYMMDD_HHMMSS.parquet`

## TROUBLESHOOTING
==================

### Common Issues:

1. **Database Connection Error:**
   ```
   Error: Could not connect to SQLite database
   ```
   **Solution:** Check if `db/trade_data.db` exists and has proper permissions

2. **No Training Data:**
   ```
   Error: No data found for symbol
   ```
   **Solution:** Ensure `db/processed_candles_with_ta.csv` exists and has data

3. **Model Not Found:**
   ```
   Error: Model not found
   ```
   **Solution:** Check if model files exist in `models/` directory

4. **Import Errors:**
   ```
   ModuleNotFoundError: No module named 'lightgbm'
   ```
   **Solution:** Install missing packages: `pip install lightgbm torch scikit-learn`

### Debug Mode:
```powershell
# Enable debug logging
$env:SL_DEBUG = "1"
python supervised\sl_workflow.py --action full_pipeline
```
